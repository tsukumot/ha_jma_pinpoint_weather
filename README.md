# JMA Pinpoint Weather for Home Assistant

気象庁が発表している「天気分布予報」を自動取得し、天気・気温・降雨量の予報を Home Assistant に表示するカスタム統合です。

また、高解像度降水ナウキャストを利用して、雨の降り始める時間を表示します。

- 地域時系列予報とは異なり、天気分布予報では約 5km の格子単位ごとに予報が出ています。
- 一次細分区域より指定地点に即した予報が得られる **かもしれません**。
- 高解像度降水ナウキャストから降水強度を取得しています。（1時間先まで）
  - 降水強度は色で示されているため、数値はあくまでも目安となります。
- 雷ナウキャスト、および突風ナウキャストの予報値も取得します。（1時間先まで）
- 気象庁のデータ提供の仕様変更により、突然使えなくなる可能性があります。

データ出典：[![気象庁](banner_jma.gif)](https://www.jma.go.jp)

## できること
- （v0.1.0）翌24時までの3時間ごとの天気予報、予想気温の取得。
- （v0.2.0）指定地点から最寄りのアメダス計測値センサーを追加。降水量とそれ以外で、それぞれ一番近い観測所を採用します。
- （v0.3.0）予想最高気温、最低気温を属性に追加。
- （v0.3.0）降水量を取得。凡例から概算で数値に変換しているため、値は目安です。降雪量は入れる場所がないため一旦保留。
- （v0.4.0）降水ナウキャストを解析し、雨の降り始める時刻をセンサーに記録。属性に取得した値（同じく目安）の一覧を表示。
  - 雨が降り続けている間は値を更新しません。
  - 予報より早く雨が降り出した場合、センサーの値はその時刻に変更されます。
  - 雨が止んでいて、雨の予報がないとき、センサーの値は 不明 になります。
- （v0.4.0）雨の予報が 15mm / 3h を超える場合、予報を `pouring` と表示。
- （v0.5.0）雷活動度が2以上であれば、現在の予報を `lightning` または `lightning-rainy` と表示。
- （v0.5.0）雷活動度、竜巻発生確度を取得するセンサーを作成。


## ライセンス・出典

- 各予報のデータは気象庁が提供するものです。利用にあたっては[気象庁ホームページの利用規約](https://www.jma.go.jp/jma/kishou/info/coment.html)に従ってください。
- 本統合は気象庁とは無関係な、非公式のものです。
