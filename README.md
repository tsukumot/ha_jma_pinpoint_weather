# JMA Pinpoint Weather for Home Assistant

気象庁が発表している天気予報を自動取得し、天気・気温・降雨・降雪の予報を Home Assistant に表示するカスタム統合です。（予定）
予報の取得には「天気分布予報」を使用しています。
また、ナウキャストも利用したいと思っています。（予定）

- 地域時系列予報とは異なり、天気分布予報では5km四方のグリッド（格子）ごとに予報が出ています。
- 一次細分区域より指定地点に即した予報が得られる**かもしれません**。
- 非公式のため、気象庁の仕様変更によりある日突然使えなくなる可能性があります。


データ出典：[![気象庁](banner_jma.gif)](https://www.jma.go.jp)

## ライセンス・出典

- 各予報のデータは気象庁が提供するものです。利用にあたっては[気象庁ホームページの利用規約](https://www.jma.go.jp/jma/kishou/info/coment.html)に従ってください。
- 本統合は気象庁とは無関係な、非公式のものです。
